# HS2 Manager

中文 Windows 11 人物卡管理器。C# / WPF / .NET 10，便携部署。采用独立 Unity 2018.4.11f1 内核预览人物，读取本机游戏和 MOD 的原始资源；日常预览不启动游戏或 Studio，不执行游戏及插件 DLL。

## 开始使用

1. 将 `HS2Manager-1.2.0-preview1-win-x64.zip` 解压到本机磁盘，例如 `D:\Apps\HS2Manager`。请完整解压，保持程序与其他文件相对位置。
2. 双击 `HS2Manager.exe`。已包含 .NET 运行时，无需另行安装。
3. 默认游戏目录为 `Z:\games\hs2\HS two DX - TSYMQ`。在左下角“设置与连接”可修改，也可添加其他人物卡目录。
4. 首次启动默认仅扫描女性人物卡目录 `UserData\chara\female` 的当前层，建立本地封面和元数据索引，再读取 MOD 清单。在“设置与连接”可开启“递归检索人物卡（包含子目录）”，该开关默认关闭，同时适用于默认目录和额外人物卡目录。关闭递归后，已索引的子目录内容仍会保留。NAS 首次扫描需要一些时间；底部显示进度并提供取消。

`Data` 在程序旁边，保存 `library.db`、`settings.json`、`Covers`、`Operations` 和 `Logs`。移动整个便携目录可以保留管理信息；游戏与原人物卡仍位于原来的目录。不要把本地数据库放到 NAS。

## 浏览与整理

- 左侧分为全部人物卡、收藏、完全重复文件、需要关注、可恢复隔离区，以及虚拟分类和真实文件夹。
- 搜索名称、文件名、标签和备注；支持性别、标签筛选及名称、修改时间、大小排序。
- 单击显示详情；双击有效人物卡打开 3D。按 Ctrl / Shift 多选，使用底部操作栏或右键菜单进行批量收藏、添加标签、分类、导出、移动和隔离。
- 标签、收藏、备注、虚拟分类保存在数据库中。编辑标签或备注后点击“保存标签与备注”或按 Ctrl+S。
- 重复检查读取完整文件并计算 SHA-256，包括 PNG 尾部人物数据。同一封面不一定是同一人物卡。
- 普通 PNG、服装卡和解析异常项显示在“需要关注”，不会冒充人物卡加载。
- 新增或外部修改文件后点击“刷新”或 Ctrl+R。此版使用手动增量刷新，不持续监视网络目录。

## 导入、导出与恢复

拖入 PNG / 文件夹，或点击“导入人物卡”。导入默认复制，按性别放入游戏 `male` / `female` 目录；同名自动保留两份。导入与导出都会逐字节保留人物数据，并校验 SHA-256。

移动、重命名、隔离也保留原始文件。隔离目录是游戏根目录下的 `.HS2ManagerTrash`，始终排除在扫描之外。左侧“可恢复隔离区”可恢复到原位置；若原名称已有文件，恢复时同样保留两份。

文件操作在 `Data\Operations` 中逐步记账。启动时自动检查未完成操作，“操作日志 → 恢复未完成操作”可再次检查。若跨盘移动中断而两端均有文件，程序保留两份并提示检查，不会擅自删除源文件。不要手动删改尚未恢复的操作记录。

NAS 离线时保留既有索引与封面；完整目录枚举失败时不会把全部人物卡标为已删除。确认目录在线后发现的缺失项会保留记录，方便检查。

## 独立 3D 预览

首次打开预览时，管理器同时启动便携包中的自有 Unity 内核和准备人物数据；预览内切换人物卡通过命名管道替换角色，复用同一进程及未变化的公共资源。界面显示共享内存中的最终 BGRA 帧。内核使用原始网格、蒙皮、Shader、材质与完整纹理；人物定义只包含数据，不执行游戏或插件脚本。

已接入 ABMX、扩展配饰、SkinnedAccessory、KSOX/KCOX、MaterialEditor、PushUp、EyeControl，以及当前整合包的超范围体形和发束滑条规则，读取捏人场景灯光、DHH 与 BetterAA 设置；待机动画、眨眼、前向视线、头发、衣物及身体动态由独立控制器计算。PushUp 仅在本机存在对应插件时应用保存参数。MOD 内直接存储的 PNG 纹理也按 Sideloader 路径解析。缺失资源、无法读取的组件与尚未实现的效果显示具体诊断。

兼容性说明已按女性目录当前层的全部 79 张卡检查，修复嵌套骨骼、贴图别名、服装资源路径和未使用参数的误报；检查范围及逐卡记录位置见 [兼容性说明修复](docs/UNITY-COMPATIBILITY.md)。

**此版本尚未达到完整 1:1 还原。** 2026-11-08 已完成 81 张卡的四视角及动态对照：静态通过 15/81，动态通过 0/81，完整验收通过 0/81。游戏对照标准、报告位置和已知差异见 [独立 Unity 预览说明](docs/UNITY-PREVIEW.md)，逐卡失败项见 [验收结果](docs/UNITY-VALIDATION-RESULTS.md)。

预览持续播放，可暂停或继续。调整灯光或背景后标记为“自定义环境”，点击“恢复游戏环境”恢复原始配置。加载失败提供原因和重试，不自动切换旧渲染器。关闭预览或管理器时，Windows Job Object 回收本次启动的内核及子进程。

旋转、平移或缩放时暂时停用会积累拖影的效果，停止操作后恢复原环境画质。预览目标帧率为 60 FPS，实际速度取决于模型和硬件；实测及验证方法见 [预览交互优化](docs/PREVIEW-INTERACTION.md)。

提取资源缓存在 `Data\UnityPreview\definitions-v1`，缓存键包含 MOD 文件大小、修改时间及归档内路径；每次打开重新解析人物和环境设置。关闭管理器后可删除 `Data\UnityPreview` 释放空间。游戏资源和用于读取元数据的游戏程序集仍须可访问；发布包不包含游戏、MOD、人物卡或提取缓存。用户无需安装 Unity 编辑器。

原始骨架、组件、形变基础数据和环境数据另存于 `Data\UnityPreview\metadata-v1`，序列化内存缓存上限 128 MiB、磁盘上限 512 MiB，按最近使用淘汰；这些上限不包括已提取资源和当前角色的纹理/显存。MOD 扫描同时记录归档目录，缓存命中时不再打开全部 MOD 包。源文件变化自动失效，缓存损坏会重建，手动更新 MOD 索引会清除缺失查询结果。加载阶段和首帧耗时记录在 `Data\Logs\preview-performance.jsonl`。性能测量与画面对照见 [加载性能验证](docs/PREVIEW-PERFORMANCE.md)。

| 操作 | 效果 |
| --- | --- |
| 左键拖动 | 环绕模型旋转 |
| 滚轮 | 缩放 |
| 右键或中键拖动 | 平移 |
| 正面 / 侧面 / 背面 | 预设镜头 |
| 面部 | 拉近并对准人物面部 |
| 复位镜头 / 双击预览 | 按模型尺寸重新取景 |
| 灯光 / 背景 / 恢复游戏环境 | 自定义环境及恢复 |
| 暂停 / 继续 | 控制人物动态 |
| 保存截图 / Ctrl+S | 保存当前内核完成后处理的画面，不含人物卡尾部数据 |
| Esc / 返回箭头 | 取消加载并释放当前模型 |

快速切换以最新选择为准，包括内核仍在启动时的切换。人物资源加载失败后重试继续复用内核；内核退出或连接中断后重试才重新启动。关闭预览取消未完成加载并结束内核进程。部分资源缺失不影响其它管理功能。程序只读游戏和原人物卡，不会整包复制游戏。

## MOD 诊断

读取已知 Sideloader 扩展引用，对照本地 `.zipmod` / `.zip` 的 `manifest.xml`，并识别已知迁移规则。详情中点击“更新”重建清单。

- **已找到**：上次扫描清单中存在对应 GUID，或通过已识别迁移映射满足。
- **缺失**：在完整扫描结果中没有该 GUID。
- **无法判断**：未建立索引、目录离线、清单损坏、未知扩展标识或无法确定的迁移规则。

这是静态诊断，不证明资源包内部每个贴图、物件或插件都可以正常加载，也不验证插件启用状态。安装或删除 MOD 后请更新索引。对无法识别的插件扩展保守显示“无法判断”。

## 主题与快捷键

左下角支持浅色、深色、跟随系统。原生标题栏支持窗口缩放；详情区、文件夹和卡片网格可独立滚动。

| 快捷键 | 操作 |
| --- | --- |
| Ctrl+F | 搜索 |
| Ctrl+R | 增量刷新人物索引 |
| Ctrl+S | 保存当前标签备注 / 预览截图 |
| F2 | 重命名单个选中卡片 |
| Delete | 将选中卡片放入隔离区（有确认） |
| Esc | 退出预览 |

## 源码构建

独立 Unity 内核和管理器视口已接入。源码构建 Unity Player 需要已激活的 Unity 2018.4.11f1；便携发布不需要编辑器。构建及视觉验收见 [独立 Unity 预览说明](docs/UNITY-PREVIEW.md)。

Windows x64，.NET 10 SDK。可先执行 `bootstrap-dotnet.ps1` 下载到项目 `.tools`；脚本从微软官方发布清单选取 SDK 并核验 SHA-512。

日常从源码启动可直接双击根目录的 `start.cmd`：优先使用 `.tools\dotnet` 中的 SDK，否则使用系统 `dotnet`，以 Release 配置增量构建并启动当前源码。预览使用最近一次成功构建的本机 Unity Player（先运行 `build-unity-preview.ps1`）；便携包始终使用自身附带的 Player。首次运行需要联网还原依赖；失败时窗口会保留错误信息。数据默认位于构建输出目录旁的 `Data`，也可在命令行通过 `start.cmd --data "D:\HS2ManagerData"` 指定。

```powershell
.\bootstrap-dotnet.ps1
.\build.ps1 -GamePath 'Z:\games\hs2\HS two DX - TSYMQ'
# 同时运行 Unity 内核通信、异常清理与 WPF 预览检查（不启动游戏）
.\build.ps1 -GamePath 'Z:\games\hs2\HS two DX - TSYMQ' -PreviewTest
```

构建脚本默认运行核心与布局检查，然后发布自带运行时的便携目录和 ZIP，写入 SHA-256。输出在 `artifacts\release`；若已有同名目录，创建带时间的新目录，不覆盖旧 `Data`。`-SkipTests` 可跳过核心与布局检查。

默认构建不依赖任何游戏程序集；桌面端为 .NET 10 WPF、SQLite 与 AssetsTools.NET。真实资源测试需要本机游戏数据。构建脚本禁用构建服务器。旧桥接源码保留在 `src/HS2Manager.Bridge`，已移出默认解决方案和发布流程；旧 Studio 启动器和协议也不再编入生产 Core 程序集，旧 `--preview` 检查入口已禁用。

目录：`src/HS2Manager.App`（MVVM 界面与原生视口）、`src/HS2Manager.Core`（人物/模型解析、缓存、索引、文件与依赖）、`src/HS2Manager.Bridge`（历史桥接源码）、`src/Shared`（旧桥接协议）、`tests`（核心、布局与独立预览检查）。

## 范围与兼容性

此版提供人物管理及独立 Unity 动态预览，不编辑人物、服装、姿势或游戏资源。当前尚未通过全部人物卡的视觉一致性验收。新的逐卡静态、动态与独立性验证见 `docs/UNITY-PREVIEW.md`；`docs/NATIVE-PREVIEW.md` 和 `docs/VALIDATION.md` 为此前渲染架构的历史记录。

若曾使用旧版本，遗留的桥接插件不会被新版启用；在游戏退出后可手动移除游戏 `BepInEx\plugins\HS2Manager` 子目录。程序没有安装系统服务或计划任务。
