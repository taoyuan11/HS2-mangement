# HS2 Manager

中文 Windows 11 人物卡管理器。C# / WPF / .NET 10，便携部署。当前为独立 3D 预览第一阶段：直接读取游戏模型资源，在 WPF 3D 视口内显示，不启动 Studio。

## 开始使用

1. 将 `HS2Manager-1.1.0-preview1-win-x64.zip` 解压到本机磁盘，例如 `D:\Apps\HS2Manager`。请完整解压，保持程序与其他文件相对位置。
2. 双击 `HS2Manager.exe`。已包含 .NET 运行时，无需另行安装。
3. 默认游戏目录为 `Z:\games\hs2\HS two DX - TSYMQ`。在左下角“设置与连接”可修改，也可添加其他人物卡目录。
4. 首次启动会递归扫描 `UserData\chara`，建立本地封面和元数据索引，再读取 MOD 清单。NAS 首次扫描需要一些时间；底部显示进度并提供取消。

`Data` 在程序旁边，保存 `library.db`、`settings.json`、`Covers`、`Operations` 和 `Logs`。移动整个便携目录可以保留管理信息；游戏与原人物卡仍位于原来的目录。不要把本地数据库放到 NAS。

## 浏览与整理

- 左侧分为全部人物卡、收藏、完全重复文件、需要关注、可恢复隔离区，以及虚拟分类和真实文件夹。
- 搜索名称、文件名、标签和备注；支持性别、标签筛选及名称、修改时间、大小排序。
- 单击显示详情；双击有效人物卡打开 3D。按 Ctrl / Shift 多选，使用底部操作栏或右键菜单进行批量收藏、添加标签、分类、导出、移动和隔离。
- 标签、收藏、备注、虚拟分类保存在数据库中。编辑标签或备注后点击“保存标签与备注”或按 Ctrl+S。
- 重复检查读取完整文件并计算 SHA-256，包括 PNG 尾部人物数据。同一封面不一定是同一人物卡。
- 普通 PNG、服装卡和解析异常项显示在“需要关注”，不会冒充人物卡加载。
- 新增或外部修改文件后点击“刷新”或 Ctrl+R。此版使用手动增量刷新，不持续监视网络目录。

## 导入、导出与恢复

拖入 PNG / 文件夹，或点击“导入人物卡”。导入默认复制，按性别放入游戏 `male` / `female` 目录；同名自动保留两份。导入与导出都会逐字节保留人物数据，并校验 SHA-256。

移动、重命名、隔离也保留原始文件。隔离目录是游戏根目录下的 `.HS2ManagerTrash`，始终排除在扫描之外。左侧“可恢复隔离区”可恢复到原位置；若原名称已有文件，恢复时同样保留两份。

文件操作在 `Data\Operations` 中逐步记账。启动时自动检查未完成操作，“操作日志 → 恢复未完成操作”可再次检查。若跨盘移动中断而两端均有文件，程序保留两份并提示检查，不会擅自删除源文件。不要手动删改尚未恢复的操作记录。

NAS 离线时保留既有索引与封面；完整目录枚举失败时不会把全部人物卡标为已删除。确认目录在线后发现的缺失项会保留记录，方便检查。

## 独立 3D 预览（第一阶段）

直接读取游戏 `abdata` 中的 Unity 2018 资源包，解析身体、人物卡选定的基础头部和发型，用 WPF `Viewport3D` 显示静态网格。旋转、缩放和平移在程序内完成，不启动 Studio、不安装 BepInEx 插件、不加载游戏 DLL，也没有逐帧截图回传。

**这是基础模型预览，不是完整人物还原。** 已读取人物卡的头部/发型编号、肤色和发色，按基础骨架连接点组合模型。尚未应用捏脸、体型、骨骼调整、服装、配饰、皮肤贴图、透明遮罩、游戏着色器、动画和 MOD。人物以基础 T 姿态显示；不同捏脸或体型的卡片可能显示相同基础网格。界面始终显示这些限制；无法解析的部件会在“部分资源未显示”中列出，不会静默启动游戏或用另一种头部替代 MOD。

首次预览建立头部与发型资源索引；解码后的网格压缩缓存到 `Data\NativePreview\native-v1`。资源文件路径、大小、修改时间变化后会重新解析，损坏缓存会重建。关闭程序后可以删除 `Data\NativePreview` 释放空间，下次预览自动重建。程序不会整包复制游戏，不会修改原始资源。当前仍需游戏资源目录可访问，缓存不是独立游戏资源发行包。

| 操作 | 效果 |
| --- | --- |
| 左键拖动 | 环绕模型旋转 |
| 滚轮 | 缩放 |
| 右键或中键拖动 | 平移 |
| 正面 / 侧面 / 背面 | 预设镜头 |
| 复位镜头 / 双击预览 | 按模型尺寸和视口比例重新取景 |
| 灯光 / 背景选项 | 调整基础灯光和背景 |
| 保存截图 / Ctrl+S | 1280×720 PNG，不含人物卡尾部数据 |
| Esc / 返回箭头 | 取消加载并释放当前模型 |

快速切换以最新选择为准，关闭预览取消未完成加载。程序没有后台游戏进程。加载失败会显示原因与重试入口；普通浏览与其他管理功能不受预览资源缺失影响。

后续工作按顺序为：服装与配饰组合及遮罩、基础贴图与透明材质、捏脸体型与骨骼变形、Sideloader 资源映射与部分 MOD 支持。技术边界与验收见 `docs/NATIVE-PREVIEW.md`。

## MOD 诊断

读取已知 Sideloader 扩展引用，对照本地 `.zipmod` / `.zip` 的 `manifest.xml`，并识别已知迁移规则。详情中点击“更新”重建清单。

- **已找到**：上次扫描清单中存在对应 GUID，或通过已识别迁移映射满足。
- **缺失**：在完整扫描结果中没有该 GUID。
- **无法判断**：未建立索引、目录离线、清单损坏、未知扩展标识或无法确定的迁移规则。

这是静态诊断，不证明资源包内部每个贴图、物件或插件都可以正常加载，也不验证插件启用状态。安装或删除 MOD 后请更新索引。对无法识别的插件扩展保守显示“无法判断”。

## 主题与快捷键

左下角支持浅色、深色、跟随系统。原生标题栏支持窗口缩放；详情区、文件夹和卡片网格可独立滚动。

| 快捷键 | 操作 |
| --- | --- |
| Ctrl+F | 搜索 |
| Ctrl+R | 增量刷新人物索引 |
| Ctrl+S | 保存当前标签备注 / 预览截图 |
| F2 | 重命名单个选中卡片 |
| Delete | 将选中卡片放入隔离区（有确认） |
| Esc | 退出预览 |

## 源码构建

Windows x64，.NET 10 SDK。可先执行 `bootstrap-dotnet.ps1` 下载到项目 `.tools`；脚本从微软官方发布清单选取 SDK 并核验 SHA-512。

```powershell
.\bootstrap-dotnet.ps1
.\build.ps1 -GamePath 'Z:\games\hs2\HS two DX - TSYMQ'
# 同时运行独立资源解析与 WPF 预览检查（不启动游戏）
.\build.ps1 -GamePath 'Z:\games\hs2\HS two DX - TSYMQ' -PreviewTest
```

构建脚本默认运行核心与布局检查，然后发布自带运行时的便携目录和 ZIP，写入 SHA-256。输出在 `artifacts\release`；若已有同名目录，创建带时间的新目录，不覆盖旧 `Data`。`-SkipTests` 可跳过核心与布局检查。

默认构建不依赖任何游戏程序集；桌面端为 .NET 10 WPF、SQLite 与 AssetsTools.NET。真实资源测试需要本机游戏数据。构建结束会关闭本次 SDK 的构建服务器。旧桥接源码保留在 `src/HS2Manager.Bridge`，已移出默认解决方案和发布流程。

目录：`src/HS2Manager.App`（MVVM 界面与原生视口）、`src/HS2Manager.Core`（人物/模型解析、缓存、索引、文件与依赖）、`src/HS2Manager.Bridge`（历史桥接源码）、`src/Shared`（旧桥接协议）、`tests`（核心、布局与独立预览检查）。

## 范围与兼容性

此版提供人物管理及实验性的基础模型查看，不编辑人物、服装、姿势或游戏资源。独立预览已针对本机 Unity 2018.4 整合包的男女样本验证，不代表全部人物卡与 MOD 兼容。新的测试记录见 `docs/NATIVE-PREVIEW.md`，`docs/VALIDATION.md` 保留旧 Studio 版本的历史验收记录。

若曾使用旧版本，遗留的桥接插件不会被新版启用；在游戏退出后可手动移除游戏 `BepInEx\plugins\HS2Manager` 子目录。程序没有安装系统服务或计划任务。
