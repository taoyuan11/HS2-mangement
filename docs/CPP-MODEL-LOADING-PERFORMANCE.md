## 变更

- UnityFS 先解析目录，访问模型或贴图时仅解压覆盖所需区间的块。单块 LZMA 包解压后释放压缩副本；序列化数据通过移动转移，减少重复内存副本。
- 外部 `.resS` 仅定位并读取当前贴图所需字节，不再读取整个资源文件。
- 读取器按估算内存和数量淘汰，替换原来的固定三个读取器限制。目标预算为 512 MiB，最多 64 个读取器；估算覆盖原始数据及已解析参数树，不代表整个程序内存上限。正在使用的单个大资源、调用方持有的读取器以及两次请求间增长的解析数据可能暂时超出预算。
- CAB 标识、着色器名称和导出别名保存为当前人物的轻量索引。读取器被淘汰后，查询名称不必重新读取并解压整个包。材质合成器也复用已成功解析的着色器名称。

缓存随当前人物资源存储释放；重新打开人物建立新的资源存储，没有新增跨人物共享的可变模型或永久资源缓存。名称查询保留导出名称、文件名和去扩展名别名的优先级，也保留缺失、歧义及取消检查。未调整网格精度、纹理尺寸或渲染效果。

## 验证与复现

完整 Release CMake / WinUI 构建通过，便携依赖审计通过（71 个原生 PE 文件），CTest **10 / 10** 通过。真实 DHH 资源包的 4 个着色器名称及别名与原查询结果一致。
