导出延续参考姿态语义，不包含待机动画与实时物理。跨引擎 BRDF、散射、透明排序及后处理仍有近似；上述结果不表示 Blender/Unreal 与预览逐像素相同，见 [模型导出说明](MODEL-EXPORT.md)。

## 发布与二进制核验

正式入口、源码启动、导出和发布均使用原生实现；历史宿主隔离在显式选择的测试项目中，没有自动回退。应用及发布目录共 527 个二进制通过实际 PE 身份、引用、导入和旧通信端点审计，原生 FBX/布料 DLL 实际装载与步进通过。交付程序已完成隔离资料库启动和正常关闭检查。微软 WinRT 的未调用 Mono 兼容声明按固定二进制哈希单独核验，说明见 [原生架构](NATIVE-GPU-PREVIEW.md)。

交付的应用、Core、Rendering、Export、FBX SDK 及两份适配 DLL 与验收文件逐字节一致。底层四份 PhysX SDK DLL 重建仅改变 COFF/调试时间和 PDB age；代码、数据及其余内容一致。另用实际交付 DLL 复跑两个含布料的基线样本，数值与局部视觉复核均通过；证据为 `artifacts/native-migration/frame-package-physics-final/packaged-cloth-validation.json`。

最终打包前已分别执行上述检查，打包阶段使用 `-SkipTests` 避免重复；发布依赖审计及原生运行库检查始终执行。包中不含游戏/MOD 资源、人物卡、Unity/Mono 运行时或历史宿主。ZIP 的 SHA-256 随包单独提供。
