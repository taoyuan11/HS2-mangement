# 本机验收记录

> 以下为 1.0.0 Studio 桥接版历史记录。1.1.0-preview.2 独立预览的范围与验收见 [NATIVE-PREVIEW.md](NATIVE-PREVIEW.md)。

日期：2026-11-07。Windows x64，.NET SDK 10.0.403 / Runtime 10.0.14。游戏：本机映射盘的 HS two DX - TSYMQ，Unity 2018.4，BepInEx 5.4.17，HS2API 1.28.1。

## 自动检查

`tests/HS2Manager.Checks --core`：30 项通过。使用独立临时目录及真实卡片副本，覆盖中文和 Unicode 路径、PNG/人物数据截断、普通图片、大文件流式解析、同名导入、完整 SHA-256、导出、重命名、移动、标签收藏持久化、隔离与同名恢复、扩大扫描根目录时排除隔离区、离线目录与重连、文件独占占用、取消、提交后索引恢复、部分拷贝回滚、单文件异常、重叠根目录去重、文件缺失、SQLite 备份、MOD 已找到/缺失/未知及迁移、设置持久化。测试结束后核对原始游戏卡片哈希未变。

大卡：144.7 MB，解析过程新增托管分配约 0.11 MB；不会把大型贴图扩展整块载入内存。

真实人物库：382 个 PNG 候选项，378 张有效人物卡、3 张普通图片、1 张服装卡。解析出 3,913 条 MOD 引用。当前 MOD 清单扫描读取 3,172 个资源包、147 个插件标识；未知扩展和不完整清单保留“无法判断”。

`tests/HS2Manager.UiChecks`：浅色、深色、系统主题 × 100% / 150% / 200% × 资源库 / 预览，共 18 张 WPF 布局渲染。以 1920×1040 物理像素模拟缩放对应的逻辑空间；网格仅创建可见区域及缓冲行，80 条测试记录分别创建约 28 / 9 / 4 个容器。此检查不等同于切换所有实体显示器的系统 DPI。

## 真实 Studio 集成

- 使用男性和女性人物卡的本地副本调用 Studio 公开加载入口，确认渲染帧持续回传。
- 1280×720 异步 GPU 读回：10 秒收到约 267 帧（26.7 fps）；WPF 实际显示随负载约 20–27 fps。
- 侧面镜头改变画面；背景设置经过真实 Studio 渲染链生效。
- 快速连续切换人物，最新请求完成，旧请求不覆盖当前选择。
- 正常停止预览后所属 Studio 消失；在 Studio 启动期间取消后，进程同样被清理。
- 实际窗口内打开人物预览、切换侧面、保存 1280×720 PNG 截图，随后关闭管理器并确认所属 Studio 退出。
- 从全新 ZIP 解压目录运行，自带运行时启动成功，重新扫描得到 378 张有效人物卡；实测搜索 Hero 得到一个结果，浅色主题切换并持久化。
- 从解压版打开真实 3D 后强制结束管理器，Windows Job Object 自动结束所属 Studio；搬迁整个便携目录后重新启动，数据库和主题设置保留。

## 验收边界

- 兼容读回代码已实现；本机支持异步 GPU 读回，未在不支持该能力的实体显卡上测试降级路径。
- 离线测试通过暂时移走独立测试目录模拟不可访问，没有断开用户 NAS 网络。网络文件系统长时间挂起仍受 Windows I/O 超时影响。
- 不宣称覆盖 378 张卡片的全部特殊 MOD 组合。当前整合包测试通过，其他整合包与画质插件可能需要适配。
- 预览输出使用现有 Studio 材质、贴图与画质链；默认人物姿态由 Studio 决定，首版没有姿势编辑。

所有测试启动的管理器、Studio 和构建服务器在最终交付前清理；游戏原人物卡未用于改名、移动或隔离测试。
