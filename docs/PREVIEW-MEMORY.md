# 角色卡预览内存优化（2026-11-13）

本轮针对原生 3D 预览中的加载源数据和着色器参数树，不调整模型精度、贴图分辨率、光照或后处理设置。

## 实现

- 读取器缓存目标预算由 512 MiB 降到 128 MiB，保留最多 64 个读取器。单个正在使用的大资源和外部借用仍可能超过该目标；它不是进程内存上限。
- GPU 管线建立、人物更新及更新后的首帧完成时，释放读取器和内存解压块缓存。已转换的网格、材质和动画仍由场景持有；磁盘解压块、CAB/着色器索引及材质名称到对象指针的轻量索引继续复用。
- 贴图转换和着色器解析使用临时参数树，完成后释放；已有元数据借用保持有效。着色器通道通过移动转移，不再完整复制，且只保留原有选择器会使用的 D3D11 平台变体。
- 后处理在加载阶段预先上传 64 张 64×64 的循环噪声贴图，避免后续帧为下一相位重新打开内置资源包；保持原有噪声相位与随机数序列。
- 首帧后的连续绘制检查要求读取器与解压块缓存驻留为零，且后续七帧不重新加载源资源。编辑流程另行检查连续体型/脸型修改、颜色修改、服装显示、配饰增删、撤销重做及快速更新。

## 测量方法

三轮独立进程的结果如下；首帧内存取中位数，峰值取三轮最大值，单位为 MiB。

| 样本 | 首帧工作集（前 → 后） | 首帧私有内存（前 → 后） | 峰值私有内存（前 → 后） | 首帧耗时中位数（前 → 后） |
| --- | ---: | ---: | ---: | ---: |
| 女性 navi | 1,108 → 663（−40.2%） | 2,071 → 1,621（−21.7%） | 2,190 → 1,737 | 3.249 → 3.634 秒 |
| 男性 HS2_ill_M_000 | 922 → 577（−37.4%） | 1,604 → 1,254（−21.8%） | 1,726 → 1,365 | 2.456 → 2.667 秒 |

峰值工作集分别由 1,120 / 934 MiB 降到 775 / 619 MiB。缩小缓存和释放源数据使本次样本首帧中位数增加约 0.39 / 0.21 秒；这次以降低占用为主要目标，不宣称全面提速。前后第 0 / 7 帧共 **12 组 SHA-256 全部一致**。

同一服务实例内女性 → 男性 → 女性的额外检查通过，6 张截图与对应基线一致；首尾女性在八帧完成后的私有内存为 1,632 / 1,644 MiB，未出现整个人物资源叠加。该短序列不能代替长时间切卡压力测试。各次数据、可执行文件哈希和阶段计数见 [测量记录](validation/preview-memory-20261113.json)。

最终 Release CTest **20/20** 通过。真实女性样本的编辑检查覆盖暂停时重绘、三种服装显示、体型/脸型/肤色/发色、扩展修改、撤销重做、配饰移除恢复和 60 次快速修改；常规参数修改期间读取器累计加载次数固定为 150，配饰拓扑变更按需重载。

真实人物检查使用 `navi.png` 和 `HS2_ill_M_000.png`、本机现有游戏资源、相同 DHH 环境与 PhysX。每个版本/人物运行三次独立进程，新旧版本交替执行；使用已有索引和磁盘解压缓存，不清空 Windows 或 NAS 缓存。

`tests/performance/Measure-NativePreviewMemory.py` 使用 Windows 进程计数器和约 20 ms 采样记录峰值私有内存、峰值工作集、进程耗时与截图哈希。检查程序另在准备、运行时、管线建立、首帧和八帧完成后记录私有内存及工作集。

私有内存表示进程独占提交量；工作集表示驻留物理内存，两者不可混用。这里测量的是独立原生渲染检查程序，不是 WinUI 窗口，也不等同于用户每张卡在任务管理器中的数值。检查视口为 512×640；窗口大小、角色 MOD 和显卡驱动会影响实际占用。

复现：

```powershell
python tests/performance/Measure-NativePreviewMemory.py `
    '<构建目录>/modules/src/HS2Manager.NativeRendering/Release/hs2_render_frame_checks.exe' `
    '<游戏目录>' '<独立测试 Data>' 'src/HS2Manager.NativeScene/Resources/classdata.tpk' `
    '<人物卡.png>' '<尚未存在的结果目录>' '<PhysX 运行库目录>'
```

追加 `--comparison-card '<另一张人物卡.png>'` 可在同一服务实例中依次加载第一张、第二张、第一张。脚本在失败或超时后也会回收它启动的检查进程。

原始截图和进程日志位于本机 `%LOCALAPPDATA%/HS2Manager/Tests/PreviewMemory-20261113`。测试不修改用户人物卡或正式资料库。
