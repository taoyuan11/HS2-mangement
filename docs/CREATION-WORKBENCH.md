# 角色卡与 Mod 创作工作台

主界面的“角色工程”“mod工程”在主内容区显示对应类型的工程列表，保留左侧导航。列表按最近修改时间倒序排列，显示名称、修改时间（UTC）、恢复快照和异常状态；右上方可新建或刷新。单击选中工程，双击或点击“继续编辑”打开，也可恢复自动快照、复制为新工程或重命名；没有快照时恢复按钮不可用。重命名留在列表，工作台“返回工程列表”返回对应分类并刷新；未保存时仍可选择保存、放弃或取消返回。工程页 Ctrl+R 刷新列表，F2 重命名所选工程，删除键不会操作人物卡。

人物详情的“以此创建新角色”直接复制当前卡，保留未知字段和插件数据，退出工作台后进入角色工程列表。新建时默认男性、女性直接读取当前游戏的原版预设，安装包不包含游戏角色资源。游戏离线或预设不兼容时会显示失败原因，也可以从已有卡创建。已有工程按保存的类型自动归类，无需迁移；无法识别类型的工程会在列表上方显示路径与原因。

## 工程与角色

工程保存在当前本机数据目录的 `Creation/Projects`。`Ctrl+S` 保存工程，自动恢复快照每 20 秒独立保存；恢复快照不会覆盖手动保存。一个工程只能由一个编辑窗口持有。复制工程会分配新包 GUID，复制导入源文件，并要求重新构建素材引用。

“角色外观”复用人物编辑页。信息分类提供姓名、性格、语音、生日和当前游戏版本支持的原生属性；性格及原生枚举选项从本机游戏数据读取。旧人物卡编辑入口仍按原有逻辑保存。

工程保存、构建 Mod、导出角色卡、导出 Mod、导出角色包和安装到游戏分别操作。编辑素材或角色后必须重新构建，才可导出、安装关联素材的成品；旧任务结果不会覆盖新的工程修订。

封面按钮显示来源及版本状态。默认封面由当前角色渲染；可选择取景方向、缩放和垂直偏移，也可导入 PNG/JPEG。新素材需要先构建，才能以游戏材质拍摄封面。导出时重新生成当前版本的渲染封面；指定的导入图片保持为用户选择的封面。

## 建模与适配

左侧选择素材和对象，中央为 D3D11 视口，右侧为变换、画笔、试穿、骨骼和贴图属性。先“添加素材”，选择配饰／发型／服装、角色槽位和游戏模板；也可以从人物外观素材槽进入创作。每个工程允许多个素材，每个槽位绑定一个素材。

- 鼠标左键选择或使用当前工具；右键拖动旋转视角，中键拖动平移，滚轮缩放。`F` 聚焦，`A` 全选，`B` 框选，`G/R/S` 移动／旋转／缩放，`X/Y/Z` 约束轴，`Delete` 删除选区，`Esc` 取消当前拖动。`Ctrl+Z/Y` 撤销／重做；一次拖动或笔画作为一次历史操作。
- 对象、顶点、边、面及 UV 岛可独立选择。变换工具可拖动坐标轴手柄，也可输入数值；吸附步长为 0 时关闭网格吸附，顶点吸附独立开启。对象可隐藏和锁定。
- “添加网格”包含基本体、曲线发片、管束、身体表面服装及 FBX/OBJ/GLB/GLTF 导入。曲线控制点可再次编辑；已经改变拓扑的曲线需要作为普通网格继续编辑，以免覆盖手工修改。
- 网格菜单提供挤出、内插、切分、环切、边／顶点倒角、细分、焊接、删除、溶解、补面、镜像、合并／分离及法线操作。倒角要求闭合且流形的相邻拓扑；溶解不能跨越不连续 UV、法线或材质。错误操作会完整回退。
- UV 菜单提供接缝、平面／柱面／球面投影、按接缝展开、岛选择与变换、松弛、打包和 SVG 导出。棋盘格用于检查拉伸。面角 UV、材质槽、权重及形变通道随拓扑操作维护；游戏容量上限为每素材 25 万三角面、100 万顶点。
- 雕刻支持移动、隆起、凹陷、平滑、压平、收紧和遮罩；半径、强度、衰减和 X 对称可调。`Ctrl` 配合遮罩画笔执行减去遮罩。雕刻使用固定拓扑，需要增加细节时主动细分。

当前体型参考通过“更新体型与姿态参考”刷新。“姿态与体型适配检查”对当前草稿进行姿态时间和单项体型变化采样，显示蒙皮后的网格；检查期间可转动和缩放视图，点击“返回编辑姿态”继续编辑。该检查不会构建 zipmod，也不会改动工程。

服装表面生成支持高度裁剪和偏移。半脱默认复用完整网格，右侧明确显示当前模式；“建立独立半脱网格”创建可编辑副本，使用试穿状态切换完整／半脱／脱下。发型与配饰在服装脱下时保持显示。

## 贴图、材质与骨骼

“UV／贴图”打开并排二维画布。贴图列表中的“网格 UV（无绘制贴图）”用于编辑当前网格的 UV；选择覆盖贴图后显示对应身体或服装的参考 UV。画笔、擦除、填充和取色均可在二维画布或三维表面使用。图层支持导入图片、透明度、隐藏和锁定；同一材质通道或覆盖目标使用一张分层贴图，避免构建时互相覆盖。材质参数和贴图通道来自选定游戏模板；更换模板时检查已使用的通道，不能保留的设置会阻止更换并说明原因。

脸部、身体和服装覆盖分别写入角色扩展。服装覆盖选择 `ct_clothesTop`、`ct_clothesBot`、`ct_inner_t`、`ct_inner_b`、`ct_gloves`、`ct_panst`、`ct_socks` 或 `ct_shoes`。服装遮罩可选择身体、内衣和内裤遮罩。需要的 Overlay 插件会列入依赖检查。

配饰使用骨骼／挂点列表设置挂点；编辑坐标为人物根坐标，构建时转换成游戏挂点的局部坐标。发型和服装支持新增骨骼、绑定姿态、权重转移、绘制、平滑、归一化、镜像及骨骼锁定。新增骨骼的绑定位置使用人物根坐标。原版参考骨骼的绑定姿态不可直接修改。动态链可启停并设置阻尼、弹性、刚度、惯性及碰撞半径；所需 BonesFramework 会列入依赖。

## 构建、成品与安装

构建保留稳定包 GUID 和素材编号，内容摘要单独用于缓存。构建依次检查几何、骨架、模板指纹、纹理、清单和引用，再回读资源包并进行原生材质试渲染。服装额外检查穿脱状态，发型／服装检查动态和体型采样。失败或取消保留工程及上次有效成品，诊断写入工程 `Builds` 目录。

独立 PNG 只包含角色数据；独立 zipmod 包含本工程素材；角色包包含当前角色和已解析的本机依赖。导出目录可直接输入本机或 NAS 完整路径，也可浏览选择；默认使用工程的 `Exports` 子目录。角色包导出后显示完整、部分或取消状态及清单位置。缺失资源或插件会明确报告，不联网安装。原生检查与真实游戏验证分别记录，原生检查通过不等同于游戏检查通过。

安装前显示目的文件、依赖和冲突。同内容跳过；本工程相同 GUID 更新备份旧版；异源同 GUID 或已被外部修改的文件阻止自动覆盖。日志记录暂存、提交和索引更新。关闭期间中断的安装会在下次打开创作入口时恢复。回退只恢复本次安装且未被外部修改的文件，遇到外部变化保留文件并报告冲突。

## 导入资源与兼容范围

导入素材复制到工程相对资源目录。GLTF 外部缓冲区／图片和 OBJ 的 MTL／贴图一并复制；外部引用必须位于模型所在目录内。缺失资源、越界路径及无法安全解析的 MTL 选项会明确拒绝。导入保留可支持的材质槽、蒙皮和多帧形变通道，游戏材质由工程选定的 HS2 模板及手工通道设置决定。

工作台不包含 AI 生成、通用动画制作、节点材质、地图或功能插件开发。网格、UV、雕刻和分层绘制算法为项目原生实现；FBX、GLTF、压缩和渲染所用第三方依赖沿用项目许可清单。
