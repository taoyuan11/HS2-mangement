# 应用与编辑性能优化

> 本文保留历史验证记录，其中根目录 `build*.ps1` 命令及参数为当时入口。当前构建使用 `scripts/build/Build-Cpp.ps1`，打包使用 `scripts/package/Publish-Cpp.ps1`；现行用法见 [开发说明](DEVELOPMENT.md)。

本轮针对文档打开、连续参数修改、撤销历史内存、列表响应和发布体积。原有网格、贴图尺寸、渲染效果、插件数据和便携运行库均保留。

## 实现

- `CharacterDocument` 的各分类参数、原始分类、扩展、块表和替换封面使用不可变共享对象。编辑只替换改变的分类，历史修订仍保持独立；比较时先检查共享身份，再按内容确认恢复和独立构造的等价数据。
- 预览服务保存扩展对应的文档快照。普通形体或颜色编辑不再反复序列化整份插件数据；扩展发生变化或恢复时重新解析。
- 搜索输入停止 120 ms 后统一筛选，性别、标签、排序及导航仍即时更新。可见卡片建立 ID 索引，减少缩略图和多选操作中的线性查找；绑定集合一次性构造。
- WinUI Release 启用函数级链接、移除未引用代码及相同代码折叠，并关闭增量链接。调试符号仍生成在开发目录中。
- 发布 ZIP 使用 Optimal 压缩。文件内容和依赖不变，压缩阶段会比原先 Fastest 更耗时。

## 测量与复现

2026-11-13，同机 Release x64，女性 navi 和男性 HS2_ill_M_000 各执行前后交替五轮，取中位数。操作系统与 NAS 文件缓存未清空，所有轮次保存结果的 SHA-256 与各自基线一致。原始数据见 [测量记录](validation/application-performance-20261113.json)。

| 测量项 | 女性：修改前 → 修改后 | 男性：修改前 → 修改后 |
| --- | ---: | ---: |
| 文档打开 | 1.039 → 0.727 ms | 0.872 → 0.787 ms |
| 100 次参数修改并保留修订 | 29.511 → 1.931 ms | 29.557 → 1.995 ms |
| 100 份历史带来的私有内存增长 | 94.465 → 4.219 MiB | 94.703 → 4.242 MiB |

这两张样本的参数处理耗时下降约 93%，历史内存增长下降约 95.5%。它们不代表整个程序的总内存或所有卡片的保证；文档打开的绝对差异不足 1 ms，未单独测量 WinUI 首屏时间。

真实 GPU 编辑回归单次记录中，形体、面部和颜色更新提交约 30–45 ms，扩展修改及恢复约 134–146 ms；这些数值包含当前测试设备和场景的开销，没有修改前的同条件预览耗时对照，也不等于屏幕呈现延迟。60 次连续修改提交最新结果，形体编辑未增加资源读取次数。

同一批编译对象关闭／开启 `OPT:REF`、`OPT:ICF`，主程序从 8,297,984 字节缩小到 6,636,032 字节，减少 **20.0%**，详见 [体积记录](validation/application-size-20261113.json)。该对照两侧均关闭增量链接，以排除旧产物和其他源码修改的影响。

`tests/performance/DocumentPerformance.cpp` 编译为 `hs2_document_performance.exe`，测量打开一张真实卡片，以及连续修改面部参数并保留 100 份修订的时间和私有内存增长。序列化和结果校验在计时之后执行；这些数据不代表 WinUI 首屏、完整 3D 加载或屏幕呈现延迟。

先保存修改前、后的 Release 检查程序，再运行：

```powershell
python tests/performance/Compare-DocumentPerformance.py `
    --before '<修改前检查程序>' --after '<修改后检查程序>' `
    --card '<女性人物卡.png>' --card '<男性人物卡.png>' `
    --output '<尚未使用的结果目录>' --runs 5
```

脚本交替启动独立进程，记录每次测量、程序 SHA-256 和中位数，并要求输入卡与最终保存结果的 SHA-256 全部一致。超时或失败时回收本次检查进程，不留下服务。

完整验证入口为 `build-cpp.ps1`；额外的真实 GPU 编辑回归使用 `hs2_preview_visibility_checks`，覆盖显示切换、形体和颜色、配饰增删、扩展修改及恢复、撤销重做、60 次连续修改与关闭。WinUI 启动及退出由 `tests/ui/Invoke-CppWinUiSmoke.ps1` 单独检查。

本轮 Release 构建、CTest 20/20（其中核心检查 103 项）、真实 GPU 编辑回归、并行发布检查及 WinUI 冒烟均通过。界面检查覆盖空库、强制结束后重启、首次扫描中关闭、80 张卡片的扫描和两次重启，并验证测试程序及运行库副本可完整删除。运行库审计通过 67 个原生 PE 文件。
