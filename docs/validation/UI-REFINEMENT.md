# C++ 界面重构验证（2026-11-14）

本轮使用独立的构建目录及测试资料库。没有读取、导入、删除或修改用户人物卡与游戏资源。

## 实施范围

修改主窗口、工程列表、创作工作台、角色编辑器、设置及共享样式；同步菜单事件类型和工具栏布局。保留 WinUI 原生控件、GridView 虚拟化、原业务操作及确认流程。

主要变化和尺寸约定见 [界面设计](../UI-DESIGN.md)。

## 验证边界

测试人物卡使用仓库自带的合成数据，创作布局宿主不加载真实人物和游戏资源。本轮没有重新执行真实 3D 外观、建模构建、游戏安装或成品导出的验收，也没有覆盖所有 Windows 显示缩放比例。

所有应用测试窗口及构建任务在验收后关闭。首次临时布局宿主在启用项目进程退出保护之前发生启动异常；原进程已结束，但 Windows 留下 PID 2620 的无线程、无句柄崩溃快照，系统拒绝终止该快照，仍占用临时 `LayoutReview.exe`。随后布局宿主启用与应用相同的进程保护，正常验证完成。该残留只涉及本次临时测试产物，需要由 Windows 释放；没有结束其他用户进程。
