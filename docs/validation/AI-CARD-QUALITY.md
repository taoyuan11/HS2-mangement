# AI 角色卡参考还原流程验证

日期：2026-11-13。版本：HS2 Agent 1.1.0。

## 改动范围

- 标注原图视图区域，裁剪后生成左参考、右原生渲染对照图，保留长宽比和原始像素尺寸。
- Agent 默认正侧背、正侧脸五视图，纯灰背景；面部可调整放大倍率和取景中心。管理器原有渲染默认保持不变。
- 滑条探测支持细小扰动、正侧双视图，以一张图板展示负向／当前／正向；不改变草稿版本和修改预算。
- 对脸、头发、身体、服装、配饰和材质逐项记录参考、观察及纠正动作。绑定角色版本、参考版本与渲染标识；旧评估和待修项不能通过最终导出。
- 未渲染的修改只标记为最佳候选，经过评估才记录为最佳版本。封面复用已评估正面图。
- 新配置默认 24 次参数修正，已有显式预算保留。技能优先解决可辨识的轮廓与比例，再处理材质和细节。

## 结果边界和启用

本次验证证明对照、探测和评估状态流程工作正常，不是一次重新制作角色的相似度验收。草稿仍有过厚发片、偏大冠饰、衣装剪裁与裙摆层次不符、透明头纱和披袖还原不足等差异。参考脸部裁剪低于 128 像素，工具标记为 `detail_limited`，不能据此宣称高精度人脸还原。真实 HS2 游戏验证为 `not_run`。

服务检查评估完整性与版本一致性，实际相似程度仍由调用方 AI 根据图像判断；没有新增视觉模型 API 或自动相似度评分。

新版可执行文件和完整技能已同步至本机 C++ 构建的 `bin/Release`。使用桌面便携包的既有 MCP 进程仍运行旧文件；部署新版 Agent 和技能并重新连接后生效。旧会话继续可读，完成前需要补充参考区域及当前渲染逐项评估。
