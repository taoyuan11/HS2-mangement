# 临时预览验证

验证日期：2026-11-11，Windows x64，Release。

## 自动检查

`build-cpp.ps1 -Jobs 4` 构建全部原生模块、运行 CTest、构建 WinUI 并审计运行库。新增 `temporary_preview` CTest，使用仓库中的小型 ZIP／7Z／RAR 夹具，不依赖本机安装的解压软件。

临时预览检查包含 88 项断言：

- ZIP、7Z、RAR 解压；三种格式的缺失密码、错误密码与正确密码。
- 路径穿越、绝对路径、备用数据流、Windows 保留名称、规范化重名、链接、CRC 损坏及容量限制。
- 单张 PNG 快照、多层中文路径、多角色排序、无效图片过滤、无角色输入失败。
- 包内同 GUID 覆盖较新本机版本、各角色目录相互隔离、共享资源及本机依赖回退、散装资源和 PNG 贴图解析。
- 取消索引、失败清理、资源租约释放、活动会话锁与失效会话清理。
- 正式数据库和 MOD 元数据未写入，输入卡片、包及本机 MOD 哈希未改变。
