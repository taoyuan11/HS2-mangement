## preview4 的覆盖和眼睑支持

- KSOX v1/v2 的身体、面部与左右眼覆盖，以及 KCOX v1 的服装覆盖进入实际材质合成。全彩 PNG 按 alpha 混合，保留不透明彩色像素；服装替换模式可清空底图。KCOX 按游戏运行时服装槽位名匹配，不能用资源 Prefab 名代替。
- MaterialEditor 增加 MainTex/BaseMap、ColorMask、AlphaMask 内嵌贴图、主贴图平铺/偏移与 RenderQueue。只修改队列不再误报为自定义着色器。其它着色器、法线及光照参数仍保留说明。
- EyeControl 读取头部 FaceBlendShape 的默认眼型开/闭形态，在蒙皮前按保存的上限混合顶点和法线，不执行游戏程序集。支持单关键帧形态；不支持的头部数据保留说明。InvisibleBody 应用身体、头部与头发显隐，保留配饰。
- 兼容性说明按已知版本的实际启用参数判断。控制器标识、未启用的物理/PushUp/AdvIK、空的怀孕参数、无规则的配饰控制与无绑定的调色板不再列为未执行效果；启用的未支持行为、未知版本和损坏扩展仍明确提示。
- MOD 解析检查同 GUID 的多个资源包，支持数字/类别名称迁移、多条迁移分支、旧 GUID 仍安装时的迁移以及按资源路径跨 zipmod 加载。找不到资源时更新旧索引后再判断，区分“未安装”与“已安装但缺类别/Slot”。
- 内嵌图片只记录文件范围，使用时才解码，避免解析大卡时分配全部贴图。preview5 将单图上限补齐到 64 MB 编码数据、8192×8192（64 Mi 像素），最长边缩到 1024；单次预览解码贴图预算 128 MB，超出时提示。

## 已有预览修复

- 替换 WPF `Viewport3D` 的透明绘制路径。旧路径即使遇到透明纹理像素也会写入深度，造成相交发片、睫毛和衣物遮挡错误；仅将透明部件移到末尾不能解决同一网格内部的相交。现在逐像素采样并按材质阈值裁切，透明区域不会写入深度，交换三角形提交顺序也得到一致画面。
- 视口和截图共用同一套透视校正、双线性采样、近裁剪与线性空间光照。截图以 2560×1440 渲染后缩小为 1280×720，保留更平滑的发丝与轮廓。实时视口最长边限制为 1100 像素；拖动期间使用最长边 720 像素，停止后自动补一帧清晰画面。后台按需绘制并合并连续镜头变化，没有常驻渲染循环。
- 保留虹膜完整明暗细节，读取卡片的瞳孔贴图、尺寸、颜色、垂直位置和眼睛高光。面部合成仍是静态近似，不包含游戏的眼球折射、视线或表情控制。
- MaterialEditor 基础颜色（Color / BaseColor / Color2–4）和 Cutoff 参数，按对象类型、服装/配饰槽位和材质名匹配。
- 首帧、连续换卡、失败后重试、隐藏预览及关闭窗口均验证实际视口状态，避免只检查导出 PNG。关闭会取消并等待正在绘制的帧。
- 修复平移方向：拖动时模型跟随鼠标，倾斜镜头下仍沿屏幕平面移动；侧面/背面预设不再因窗口或人物列表宽度变化而跳回正面。
- 修复 MOD 内同名贴图/模型入口冲突：只选择 GameObject，不再误将贴图当作模型而触发空引用。无法解析的第三方辅助组件保留诊断，其它可用网格继续显示，不再整件跳过衣服或配饰。
- 发型和发型配饰读取清单指定的 TexD/TexC，并支持引用游戏基础包中的贴图，修复部分跨包发型缺失纹理和透明遮罩。

## 加载链路

直接读取人物卡的 Custom、Coordinate 与已支持的 KKEx 扩展，按选定头部、头发、衣服及配饰组装静态模型。游戏与原卡只读，不启动 Studio，也不安装或执行 BepInEx 插件。

- AssetsTools.NET 解析 Unity 2018 内嵌类型树、Prefab、骨架、材质和网格。覆盖独立顶点流、Float32/Float16、16/32 位索引、submesh/baseVertex、法线、UV、bind pose 和四骨骼蒙皮。
- 从本机游戏的 shape animation 和分类表读取捏脸/体型关键帧，并用受限数值解释器读取已安装 `Assembly-CSharp.dll` 的形变公式。只接受固定数值操作和骨骼设置指令，不通过 CLR 加载游戏程序集、不调用游戏方法。衣服和头发使用同一变形骨架。
- 加载衣服完整状态、可选部件、互斥关系与身体/内衣遮罩；配饰使用卡片保存的连接点、两级位移、旋转和缩放。
- 解码基础皮肤、服装、头发、眼睛与透明遮罩；按子网格配置材质和卡片颜色。服装颜色遮罩的黑色/R/G/B 分别对应颜色 1/2/3/4。妆容、眉毛、虹膜采用独立预览器的近似合成。
- Sideloader 按 GUID、类别和 Slot 查找 zipmod CSV 及包内资源，支持已有迁移索引。基础资源的 manifest 依赖用于查找跨包贴图；找不到的资源逐项提示，不用相同数字的基础 ID 冒充 MOD。
- 读取 ABMX v2 骨骼数据（含 LZ4 压缩）、MoreAccessories 扩展配饰及上述贴图、材质和眼睑扩展。大型图片流式索引，只解码当前外观用到的贴图。
- WPF 宿主内完成旋转、缩放、平移、正侧背面镜头、面部取景、灯光、背景和 1280×720 PNG 截图。快速换卡以最新请求为准，关闭会取消加载、清空模型并释放数据。

## 缓存与文件

`Data/NativePreview/native-v8` 保存原始 Prefab、贴图、资源清单及按需解出的 MOD 资源包。缓存键包括源路径、大小、修改时间和相关依赖；不缓存人物最终外观与内嵌覆盖贴图，避免捏脸、眼睑或颜色串卡。损坏的网格缓存会从源资源重建。因模型引用和组件解析修复，旧版本缓存不复用，可在关闭程序后删除旧缓存目录。

首次 MOD 预览可能扫描整个 MOD 清单，NAS 上耗时取决于网络与资源数量。需要游戏资源和 `HoneySelect2_Data/Managed/Assembly-CSharp.dll` 可访问。缓存不是可脱离游戏的资源包。关闭程序后可删除 `Data/NativePreview` 释放空间；不会修改游戏或原卡。

发布包只含应用及开源运行库，不含游戏 DLL、人物卡、MOD、网格缓存、截图或开发时的资源检查文件。

## 兼容边界

这是可交互的独立静态预览，**尚不等同于游戏内完整视觉还原**：

- 固定基础姿态，没有表情、动画、物理、布料及动态骨骼模拟。
- 独立视口使用基础光照与简化的光泽/金属度/自发光，未复现 Unity 游戏 Shader、法线细节、皮肤散射、环境反射、真实发丝高光、眼球折射或画质插件。透明采用裁切，不能准确表现全部半透明层。
- 眉毛、眼睛与妆容为近似合成；部分面部遮罩、衣服图案、MaterialEditor 复制材质、非基础贴图与着色器参数尚未还原。皮肤/眼睛底层覆盖的合成位置为静态近似。复杂 MOD 的颜色、眼周或局部位置可能仍与游戏不同。
- ABMX v2、PushUp v3 与上述配饰规则支持已验证的静态行为；高级连接点、其它插件变形及动态模拟仍不支持，界面列出剩余效果。
- 压缩顶点、外置顶点流、无法定位的跨 MOD CAB 引用和非三角形拓扑不支持。内置模型和可定位的跨包 Mesh 已支持。某个部件失败时保留其它可显示部分并列出原因。
- 不承诺所有整合包/游戏版本/人物卡兼容；资源或形变指令版本不匹配会报告错误。
