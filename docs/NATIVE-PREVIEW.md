# 独立 3D 人物预览

2026-11-07，1.1.0-preview.2。

## 加载链路

直接读取人物卡的 Custom、Coordinate 与已支持的 KKEx 扩展，按选定头部、头发、衣服及配饰组装静态模型。游戏与原卡只读，不启动 Studio，也不安装或执行 BepInEx 插件。

- AssetsTools.NET 解析 Unity 2018 内嵌类型树、Prefab、骨架、材质和网格。覆盖独立顶点流、Float32/Float16、16/32 位索引、submesh/baseVertex、法线、UV、bind pose 和四骨骼蒙皮。
- 从本机游戏的 shape animation 和分类表读取捏脸/体型关键帧，并用受限数值解释器读取已安装 `Assembly-CSharp.dll` 的形变公式。只接受固定数值操作和骨骼设置指令，不通过 CLR 加载游戏程序集、不调用游戏方法。衣服和头发使用同一变形骨架。
- 加载衣服完整状态、可选部件、互斥关系与身体/内衣遮罩；配饰使用卡片保存的连接点、两级位移、旋转和缩放。
- 解码基础皮肤、服装、头发、眼睛与透明遮罩；按子网格配置材质和卡片颜色。服装颜色遮罩的黑色/R/G/B 分别对应颜色 1/2/3/4。妆容、眉毛、虹膜采用独立预览器的近似合成。
- Sideloader 按 GUID、类别和 Slot 查找 zipmod CSV 及包内资源，支持已有迁移索引。基础资源的 manifest 依赖用于查找跨包贴图；找不到的资源逐项提示，不用相同数字的基础 ID 冒充 MOD。
- 读取 ABMX v2 骨骼数据（含 LZ4 压缩）、MoreAccessories 扩展配饰与 MaterialEditor 的渲染器显示状态。大型扩展贴图字段流式跳过。
- WPF 内完成旋转、缩放、平移、正侧背面镜头、面部取景、灯光、背景和 1280×720 PNG 截图。快速换卡以最新请求为准，关闭会取消加载、清空模型并释放数据。

## 缓存与文件

`Data/NativePreview/native-v5` 保存原始 Prefab、贴图、资源清单及按需解出的 MOD 资源包。缓存键包括源路径、大小、修改时间和相关依赖；不缓存人物最终外观，避免捏脸或颜色串卡。损坏的网格缓存会从源资源重建。

首次 MOD 预览可能扫描整个 MOD 清单，NAS 上耗时取决于网络与资源数量。需要游戏资源和 `HoneySelect2_Data/Managed/Assembly-CSharp.dll` 可访问。缓存不是可脱离游戏的资源包。关闭程序后可删除 `Data/NativePreview` 释放空间；不会修改游戏或原卡。

发布包只含应用及开源运行库，不含游戏 DLL、人物卡、MOD、网格缓存、截图或开发时的资源检查文件。

## 兼容边界

这是可交互的独立静态预览，**尚不等同于游戏内完整视觉还原**：

- 固定基础姿态，没有表情、动画、物理、布料及动态骨骼模拟。
- WPF 使用基础光照，未复现 Unity 游戏 Shader、法线细节、皮肤散射、金属/反射、发丝高光、眼球折射或画质插件。透明采用裁切，不能准确表现全部半透明层。
- 眉毛、眼睛与妆容为近似合成；部分面部遮罩、衣服图案、自定义皮肤/服装覆盖贴图及 MaterialEditor 材质参数尚未还原。复杂 MOD 的颜色、眼周或局部位置可能仍与游戏不同。
- ABMX 仅支持已验证的 v2 静态参数；其它插件的变形、配饰逻辑与材质行为不会执行，界面列出未支持扩展。
- 压缩顶点、外置顶点流、跨包 Mesh、跨 MOD 的未声明资源依赖和非三角形拓扑不支持。某个部件失败时保留其它可显示部分并列出原因。
- 不承诺所有整合包/游戏版本/人物卡兼容；资源或形变指令版本不匹配会报告错误。

## 本机验证

Windows x64，.NET SDK 10.0.403；本机 `HS two DX - TSYMQ`，Unity 2018.4.11f1。使用原卡的临时副本，核对源卡 SHA-256 未变。

- 男性样本 66,686 个三角形；女性样本 85,017 个三角形。资源读取约 3.6 秒，缓存读取约 0.5 秒；这是当前本机测量，未清空系统磁盘缓存，不包括 WPF 构建与首次程序启动。
- 复杂 MOD 样本 121,229 个三角形，读取 44 条 ABMX 参数，覆盖服装、配饰、头发、贴图与渲染器隐藏；缺失资源和不支持扩展显示诊断。
- 修改卡片副本的捏脸与体型后，头部、身体和服装坐标确实变化；修改服装颜色可见于材质。再次读取原卡与原结果一致，验证缓存隔离。
- 覆盖缓存命中/损坏恢复、取消、缺失 MOD 不替换、顶点与索引合法性、颜色遮罩通道、透明遮罩、眉毛数据通道、骨骼调整及循环拒绝。144.7 MB 大卡外观读取约分配 0.82 MB，不分配未支持的嵌入贴图。
- WPF 检查覆盖真实视口、正侧镜头差异、面部取景、缩放/平移、背景灯光、720p 截图、连续换卡及关闭取消。渲染截图用于人工检查；这些检查不代表与游戏截图逐像素一致。
- 30 项核心管理、三主题 × 三缩放 × 资源库/预览共 18 种布局、四种空闲/忙碌窗口关闭回归均通过；另以真实像素验证透明覆盖层不会遮掉后方不透明表面。
- 确认没有加载 Unity/BepInEx/游戏程序集，没有启动游戏进程。

```powershell
.\build.ps1 -GamePath 'Z:\games\hs2\HS two DX - TSYMQ' -PreviewTest

.\build.ps1 -PreviewTest -PreviewCard '完整人物卡路径.png'
```
