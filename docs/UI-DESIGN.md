# 界面设计与验收

沿用 WinUI 3 原生控件和资源库的中性色风格，使用系统强调色表达主要操作。界面调整不改变人物卡、游戏资源及导出格式。

本文规则适用于当前 C++ / WinUI 3 界面。文末保留迁移前 C# 版本的历史记录；当前验证范围见下文及 [C++ 验证结果](CPP-VALIDATION.md)。

## 视觉与交互规则

- 主标题 28 px，正文和操作文字 14 px，辅助信息至少 12 px。较长标题省略并提供完整提示；说明和路径按内容换行。
- 搜索与筛选统一为 36 px 高，控件间隔 8–12 px。按钮文字与 Fluent 字体图标独立排版，图标采用 20 px 宽槽位、16 px 字号，不用空格或表情字符凑齐。
- 导航项至少 44 px 高，当前页面使用选中底色。切换主导航会清除文件夹、虚拟分类的旧选中态，避免同时指示多个位置。
- 详情主要操作等宽，永久删除使用危险色；确认仍默认取消。离线和异常状态采用警示色，辅助文字在深浅主题下保持可读对比度。
- 自动换行容器按整行高度对齐内容；预览工具栏按镜头与环境分组，在空间不足时整组换行。
- 预览加载或失败时禁用截图、镜头及环境控制；返回与重试保持可用。暗色预览错误区固定使用暗色控件主题。
- 空状态区分搜索无结果、收藏、重复文件、需要关注、隔离区、文件夹和虚拟分类。组合图标按钮显式提供无障碍名称。
- 设置主题选项的单选标记与名称对齐，预览色板位于名称下方；内容区域独立滚动，底部保存与取消保持固定。

## 2026-11-14 界面重构

- 导航按人物库、创作工程、虚拟分类、文件夹排列。角色工程和 MOD 工程采用与资源库一致的图标槽位、文字对齐和选中反馈。
- 常用按钮、输入框和下拉框最小高度为 36，圆角为 6；工具栏横纵间距为 8。保留 WinUI 原生焦点、悬停、按下与禁用状态，不自绘替代控件。
- 人物卡网格按可用宽度均分完整列，保持虚拟化和多选。详情栏在有结果时保持稳定，避免选中卡片后整页跳动；空结果收起详情栏。
- 批量栏只保留收藏、标签、分类、导出和更多；隔离区另显示恢复。3D 模型导出及永久删除移至更多菜单，永久删除独立分隔并标红，原确认和快捷键保持一致。
- 预览页将返回和角色标题放在第一行，动作放在第二行，避免长名称被右侧按钮挤占。预览不可用时禁用编辑页的镜头、动作和环境控制。
- 创作工作台将返回、工程名称、撤销/重做、保存放在页头；工作模式使用带选中状态的切换按钮。导出与工程选项使用原生菜单；取消任务仅在工作期间出现。
- 建模工具按网格、选择/工具、视图分组换行；右侧参数按变换与笔刷、人物适配、骨骼与权重、贴图与图层折叠。工程列表底部命令也可换行，不再依赖横向滚动条。
- 设置中的额外目录列表按内容伸缩，限制最大高度后独立滚动。底部状态栏高度为 40，容纳完整按钮点击区域。

构建与验证记录见 [本轮界面验证](validation/UI-REFINEMENT.md)。
