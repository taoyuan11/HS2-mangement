# 原生迁移性能测量

2026-11-11，同机顺序运行历史 WinUI 与正式原生版本。完整 84 张卡视觉门槛已经通过；不设性能提升比例门槛。

## 结论

本轮原生版本性能退化：热切卡中位数从 31.83 秒增加到 51.55 秒，重开从 37.14 秒增加到 52.56 秒，单次编辑响应从 7.84 秒增加到 28.47 秒。四组稳态完成帧间隔中位数由约 16.7 毫秒增加到约 31.0 毫秒，约相当于 60 → 32 帧/秒。私有内存增加约 8%–51%。

CPU 占用下降约 45%–63%，但同时完成帧率更低，不能据此认定整体效率提升。最繁忙 GPU 引擎占用增加约 14%–39%；专用显存三组减少、一组增加。以下保留所有退化结果，没有通过降低画质调整结论。

## 条件与限制

- Windows 11 专业版，10.0.26300；AMD Ryzen 5 9600X，6 核/12 线程；约 16 GB 内存。
- AMD Radeon RX 9070 GRE，驱动 32.0.32015.7029。
- 应用、运行时及缓存位于本机；源卡及游戏/MOD 资源位于同一 NAS。两版独立进程顺序运行，没有与构建或其他测试并行。
- 同一四组卡、相同 SHA-256、冻结正面镜头和 1280×720 渲染；相机更新后等待两个完成帧才结束操作计时。原生测量使用便携包中的实际原生 DLL。
- 两版分别从空应用缓存开始；没有清空操作系统或 NAS 缓存。首张卡同时承担目录扫描成本，后续首次加载也受已热身的共享索引影响，不等于四次独立机器冷启动。
- 每组首次加载一次、切卡两次、重开一次；编辑页打开和参数修改各一次。汇总中位数/P95描述本轮样本，不代表稳定的总体分布；只有一次的项目，P95等于该次测量。
- 每组预热 2.2 秒后采样 12 秒；帧间隔使用全部完成帧，CPU/GPU/内存每秒采样一次，所有计数器均可用。
- 完成帧间隔包含调度、节流及实际呈现路径，并非纯 GPU 绘制耗时。GPU 为拥有进程中最繁忙引擎的 PDH 利用率；CPU 降低不能脱离吞吐变化解释。
- 检查结束确认原卡 SHA-256 未变，测试宿主和它拥有的 Player 已退出。

完整指标含中位数/P95、工作集及显存，见 [性能 CSV](NATIVE-PERFORMANCE.csv)。原始 18 项操作与逐秒记录保存在本机 `NativeChecks/task-20261111-final/performance-reference-final/performance.json` 和 `performance-native-final/performance.json`；计算结果为 `artifacts/native-migration/performance-production-final`。
